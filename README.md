# Employee Analytics Dashboard | Power BI

An interactive Employee Analytics Dashboard built with Power BI to analyze workforce distribution, compensation, employee performance, hiring trends, and remote work patterns.

##  Project Overview

This project focuses on transforming employee data into meaningful business insights through an interactive Power BI dashboard.

The dataset contains 308 records representing 300 unique employees.

The dashboard provides an overview of:

- Workforce distribution
- Employee hiring trends
- Salary distribution
- Department-wise salary
- Employee performance
- High performers
- Remote vs on-site workforce
- City-wise employee distribution

##  Tools Used

- Power BI
- DAX
- Excel
- Figma

##  Key KPIs

| KPI | Value |
|---|---:|
| Total Unique Employees | 300 |
| Total Payroll | 17.88M |
| Average Salary | 59.60K |
| Average Performance | 3.59 |
| Remote Workforce | 41.00% |
| High Performers | 169 |
| High Performer % | 56.33% |

> High Performer is defined as a unique employee with a performance rating of 4 or 5.

##  Dashboard Analysis

### Workforce Overview

Analyzed employee distribution across:

- Departments
- Cities
- Remote and on-site work modes

### Salary Analysis

Analyzed:

- Average salary
- Total payroll
- Salary distribution
- Department-wise average salary

### Performance Analysis

Analyzed employee performance ratings and identified high-performing employees based on ratings of 4 or 5.

### Hiring Trend

Analyzed employee joining trends from 2018 to 2024 to understand workforce changes over time.

##  Key Insights

- Engineering and Sales have the largest employee populations.
- 41% of unique employees work remotely.
- Average salary is approximately 59.60K.
- 56.33% of unique employees are classified as high performers.
- Hiring remained relatively consistent from 2018 to 2023, followed by fewer unique hires in 2024.

##  Dashboard Design

The dashboard was planned and designed using Figma and developed in Power BI.

The design uses a clean light theme with:

- KPI cards
- Interactive slicers
- Minimal UI
- Consistent color palette
- Clear visual hierarchy
